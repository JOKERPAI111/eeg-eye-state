# EEG 睁闭眼二分类

用公开数据集（UCI EEG Eye State）做二分类，搞清楚"准确率"在这个任务上到底可不可信。

## 数据
- 14,980 行 × 15 列

## 发现

### 发现 1：数据里有孤立极值，会毁掉整条通道

第一版波形图里，P7 和 AF4 是两条直线。排查后发现：
- P7 中位数 4,618，最大值 362,564（相对中位数 78 倍）
- AF4 中位数 4,355，最大值 715,897（164 倍）
- 全表共 134 个点超出 [中位数 ± 10×MAD]，仅占 0.064%

原因：用 z-score（减均值除标准差）时，单个极值就能把标准差撑大 100 倍，其余正常波动被压成近似常数。

处理：改用中位数/MAD 做稳健标准化。

### 发现 2：截断阈值把眨眼也削平了

用 ±10×MAD 截断后，P7/AF4 恢复正常，但图上出现平顶。

实测：
- 10×MAD 截掉 134 个点；只删 |x|>100000 只删 8 个
- 正常眨眼幅度约 10–20×MAD（F7 9 倍、FC5 21 倍）
- 真正的坏点达 3 万×MAD（P7 31395 倍、AF4 32275 倍）

结论：眨眼和坏点差三个数量级，10×MAD 太紧。
修正：阈值改为 200×MAD（或只删 |x|>1e5），保留眨眼。

### 发现 3：标签成段连续，随机切分会泄漏

每 500 个采样点的阳性率在 0.00–1.00 之间跳变，说明标签成段出现，不是随机打散。

含义：随机 K 折会把同一时间段的数据同时放进训练集和测试集，等于把答案漏进去。
